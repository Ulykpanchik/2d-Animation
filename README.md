
# 2D Game

This is my 2D platformer game developed in Unity.

## About the Game
The player must complete levels, avoid enemies,
collect coins, and reach the portal.

## Features
- Player movement and jumping
- Shooting mechanics
- Enemies and boss fight
- Coin collection
- Portals and level transitions
- Health system
- Mobile controls
- Main menu and pause menu

## Levels
- Level 1
- Level 2
- Boss Fight

## Controls
- Move: A / D
- Jump: Space
- Shoot: F
- Mobile: On-screen buttons

## Made With
- Unity
- C#
